1. Executive Summary

Modern distributed cloud infrastructures emit high-velocity telemetry streams (CPU, memory, latency, network I/O) that require both sub-millisecond streaming anomaly detection and intelligent, context-aware operational triage. Traditional machine learning detectors (such as unsupervised isolation trees or streaming clustering) detect outliers rapidly but suffer from extreme false positive rates (>80%) and are incapable of diagnosing root causes or executing mitigation actions.

This project presents the Agentic Streaming Analytics Framework, a decoupled two-stage architecture:

  • Stage 1 (Streaming Ingestion & Online Scoring): Processes continuous metric streams via Apache Kafka and the AADS algorithm at >2,500 events/sec with sub-millisecond latencies (<0.4 ms).
  • Stage 2 (Agentic Triage & Autonomous Self-Healing): Anomaly candidates are routed asynchronously to a LangGraph-based autonomous agent. The agent runs statistical drift tests (Kolmogorov-Smirnov), queries episodic incident memory, and dispatches real-time mitigation actions (e.g., pod scaling, workload throttling, or dynamic threshold adaptation).
Key Experimental Milestone: The proposed system boosts anomaly detection F1-score from 0.194 to 0.868 (+347%) while dropping the false positive rate from 83.4% down to 0.41% compared to traditional streaming baselines.
